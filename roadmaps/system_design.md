# System Design Roadmap
1. Basics: client-server, HTTP, DNS, CDN
2. Databases: SQL vs NoSQL, indexing, replication, sharding
3. Caching: LRU, write-through/back, Redis
4. Scaling: load balancers, consistent hashing, queues
5. Reliability: rate limiting, retries, CAP, idempotency
6. Case studies: URL shortener, chat app, news feed, video streaming
