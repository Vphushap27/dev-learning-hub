# 📚 Dev Learning Hub

Algorithms, System Design aur Roadmaps - sab ek repo mein, **runnable Python code** ke saath. Zero dependencies.

## Quick start
```bash
git clone <your-repo-url> && cd dev-learning-hub
python run.py list            # sab options
python run.py run all         # saare demos
python run.py run graphs      # ek demo
python run.py roadmap dsa     # roadmap padho
python -m unittest discover -s tests -v   # tests
```

## Structure
| Folder | Content |
|---|---|
| `algorithms/` | Binary search, sorting, BFS/DFS/Dijkstra, DP, LRU cache |
| `system_design/` | Rate limiter, URL shortener, consistent hashing |
| `roadmaps/` | DSA, System Design, Backend roadmaps |
| `tests/` | Unit tests |
